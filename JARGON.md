# Jargon Buster

Simple meanings for the technical words in this project. The README does not use these words where possible. This file has the accurate words for readers who want them.

**Carbon-aware scheduling**
A method that runs work which can wait at times or in places where the electricity grid makes less carbon.

**Carbon intensity**
The quantity of carbon that the grid makes for each unit of electricity. It changes with the time and the place.

**Compounding context loop**
The Green Software Foundation name for the way an agent sends the full conversation to the model again on each turn. Thus, each turn reads more text than the turn before it.

**Embodied carbon**
The carbon that the manufacture of the computers and chips made. A part of it belongs to each run of your agent.

**Energy**
The electricity that the computers use to run your agent. People measure it in kilowatt-hours (kWh).

**Estimate**
A calculated figure that is not measured. This guide shows each estimate as a range.

**Functional unit**
The unit that you use to compare footprints, for example one run of your agent.

**Grid**
The network that supplies electricity. A grid with more wind and solar power makes less carbon.

**Operational carbon**
The carbon that the electricity for each run makes.

**Range**
A low figure and a high figure. The real value is probably between them.

**Reduction lever**
A change that makes the footprint smaller, for example a smaller model for easy steps.

**Retry**
A second attempt after a step fails. Each retry sends tokens to the model again.

**SCI**
Software Carbon Intensity. A specification from the Green Software Foundation that calculates carbon for each functional unit. It is also the standard ISO/IEC 21031.

**SCI for AI**
An extension of SCI for AI systems.

**Standing prompt**
The fixed instructions that go to the model with each turn.

**Token**
A small part of a word. Models read and write text as tokens, and providers bill for them.

**Turn**
One step of the agent loop: the model reads, thinks, and writes or calls a tool.

**Water footprint**
The water that the data center uses to cool its servers, and the water that the production of its electricity uses.
